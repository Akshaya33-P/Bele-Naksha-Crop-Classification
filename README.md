# Bele Naksha: AI-Based Crop Classification and Yield Prediction

## Project Overview

Bele Naksha is a research project exploring the use of satellite imagery and artificial intelligence for crop classification and crop yield estimation. It uses Sentinel-2 Earth observation data, geospatial preprocessing, vegetation indices, and AI-based approaches to agricultural analysis.

## Objectives

- Analyze Sentinel-2 satellite imagery for agricultural applications.
- Explore crop classification using geospatial AI models.
- Study vegetation conditions using the Normalized Difference Vegetation Index (NDVI).
- Explore approaches for estimating crop yield using satellite-derived information.

## Project Workflow

### 1. Satellite Data Acquisition
Identify suitable Sentinel-2 imagery for the study area and analysis period.

### 2. Data Preprocessing
Prepare and process satellite imagery using Google Earth Engine for subsequent analysis.

### 3. Crop Classification
Explore the application of the Prithvi-EO-2.0 geospatial foundation model for crop classification.

### 4. Vegetation Analysis
Use NDVI to examine vegetation conditions and crop growth patterns.

### 5. Yield Estimation
Explore the use of vegetation indices and satellite-derived features for crop yield estimation.
